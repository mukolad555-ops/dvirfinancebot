# DvirFinance Bot v6.0 AI FIRST

## Що змінило

У цій версії штучний інтелект читає природний текст **перед** широкими локальними правилами.
ШІ не має прямого доступу до бази: він лише перетворює повідомлення на чітку команду, а `main.py` перевіряє та виконує її.

Приклади:

- `Боря Гуцул повернув 1000 грн` → зменшення боргу + 1000 грн у касу.
- `Болена скинула Андрію на Приват 25000 грн` → надходження на ПриватБанк Андрія.
- `орендар Петро дав 4000 за оренду` → платіж орендаря + 4000 грн у касу.
- `сьогодні склад 20000 грн, базар 5000 грн` → окремі джерела виручки, разом +25000 грн у касу.
- `з картки Миколи заплатили 3000 грн за товар` → витрата з картки Миколи.

## Що замінити в GitHub

Замінити обов'язково:

- `main.py`

`README.md` можна також замінити як інструкцію.

Не запускати `reset_data.sql`: існуючі дані залишаються.

## Обов'язкові змінні Railway

У Railway → Variables повинні бути:

- `TELEGRAM_BOT_TOKEN`
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `OPENAI_API_KEY` — обов'язково для режиму ШІ
- `OPENAI_MODEL` = `gpt-5-mini` (можна не створювати: це значення за замовчуванням)
- `AI_FIRST_MODE` = `true` (можна не створювати: увімкнено за замовчуванням)

Ключ OpenAI не вставляти в GitHub і не надсилати в Telegram.

## Перевірка після Deployment successful

Написати боту одним словом:

`ші`

Правильна відповідь:

`Режим ШІ увімкнено`

Потім перевірити:

1. `Боря Гуцул повернув 1000 грн`
2. `Болена скинула Андрію на ПриватБанк 25000 грн`
3. `орендар Петро заплатив 4000 грн оренда`
4. `сьогодні склад 20000 грн базар 5000 грн`
5. `каса`

Якщо OpenAI тимчасово недоступний, бот переходить на старі локальні правила й не падає.
