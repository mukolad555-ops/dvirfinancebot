# DvirFinance v4.0 AI

Фінальна робоча версія Telegram-бота для спільного обліку двох власників.

## Що працює

- одна спільна **Фастівська каса** у ₴, $ та €;
- **Базар** — лише денна виручка, яка відразу додається до Фастівської каси;
- картка Миколи та картка Андрія;
- орендарі, борги, оплати боргів;
- скасування останньої операції;
- OpenAI розуміє звичайні фрази українською та російською;
- два власники працюють у спільній базі, а кожна операція зберігає Telegram-користувача, який її вніс.

## Railway Variables

Обов'язково мають бути:

- `TELEGRAM_BOT_TOKEN`
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `OPENAI_API_KEY`

Рекомендовано:

- `OPENAI_MODEL=gpt-5-mini`
- `OWNER_TELEGRAM_IDS=ID_МИКОЛИ,ID_АНДРІЯ`
- `WORKSPACE_CHAT_ID=СПІЛЬНИЙ_ID_КАСИ`

Щоб отримати Telegram ID, кожен власник надсилає боту `/id`.

`WORKSPACE_CHAT_ID` має бути однаковим для обох власників. Найпростіше — поставити ID Миколи як спільний ID. Тоді обидва приватні чати працюватимуть з однією касою.

## Початок з чистого листа

Перед запуском один раз відкрийте Supabase → SQL Editor, вставте весь файл `reset_data.sql` і натисніть **Run**.

Це видалить усі тестові операції, залишки, орендарів і борги. Структура таблиць та налаштування не видаляються.
