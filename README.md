# DvirFinance Bot v5.2

Оновлена стабільна версія Telegram-бота для спільного обліку грошей.

## Що нового

- Команда `відміна` скасовує останню логічну операцію.
- Переказ або обмін скасовується повністю, а не одним рядком.
- Виручка з кількома валютами в одному повідомленні записується повністю.
- Коми, пробіли та переноси рядків не мають значення.
- Підтримуються: `гр`, `грн`, `₴`, `$`, `USD`, `€`, `EUR`, долари, євро.
- `сьогодні` показує звіт за поточний день.
- Однослівні команди без суми показують правильний приклад і нічого не записують.

## Приклади

```text
виручка 27000 грн 1200 $ 100 €
виручка каса 25000 грн 300 $ 150 € базар 3000 грн
витрата 2500 грн пальне
ревізія 125000 грн у касі
каса
сьогодні
історія
відміна
```

## v5.2 — розумні банківські рахунки

Бот розуміє зовнішні надходження природною мовою і записує їх як дохід, а не як витрату.

Приклади:

- `Андрій отримав від Болени 25000 грн` → Картка Андрія
- `Болена скинула Андрію на ПриватБанк 25000 грн` → ПриватБанк Андрія
- `Від Болени прийшло 25000 грн на ФОП Миколи` → ФОП Миколи
- `Болена перевела Миколі на Банк Південний 25000 грн` → Банк Південний Миколи

У команді `каса` ці рахунки показуються окремо.


## Картки Миколи та Андрія

Короткі записи тепер розуміються напряму:

```text
на карту Миколи 8000 грн
на картку Андрія 5000 грн
```
Це надходження на відповідну картку.

```text
з карти Миколи 3000 грн за товар
із картки Андрія 1500 грн доставка
```
Це витрата з відповідної картки.

Так само працюють конкретні рахунки: ФОП, ПриватБанк, Банк Південний.
