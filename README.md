# DvirFinance Bot v6.1 AI ACCOUNTANT

## Що змінило

- ШІ першим читає звичайну українську або російську фразу.
- ШІ визначає: надходження, витрату, переказ, борг, повернення боргу, орендаря, склад або базар.
- Якщо напрямок грошей неоднозначний, бот нічого не записує і ставить коротке уточнювальне питання.
- Усі зміни балансу й надалі виконує перевірений код, а не сама модель OpenAI.
- Склад і Базар — різні джерела виручки, але гроші додаються до Каси.
- Платіж орендаря додається до Каси, якщо інший рахунок не вказано.
- Повернення боргу зменшує борг і додає гроші на названий рахунок або до Каси.

## Встановлення

У GitHub замінити:

- `main.py`
- `README.md` — необов'язково, це лише інструкція.

Не змінювати `requirements.txt`.

У Railway мають залишитися змінні:

- `TELEGRAM_BOT_TOKEN`
- `SUPABASE_URL`
- `SUPABASE_KEY`
- `OPENAI_API_KEY`

## Обнулення перед новим стартом

Файл `RESET_TO_ZERO.sql` повністю очищає робочі дані: касу, картки, історію операцій, борги та платежі орендарів.

1. Supabase → SQL Editor → New query.
2. Вставити весь текст із `RESET_TO_ZERO.sql`.
3. Натиснути Run один раз.
4. У Telegram написати `каса` — усі грошові залишки мають бути нульовими.

## Приклади природних записів

- `Болена перекинула Андрію 25000 грн на Приват`
- `З картки Миколи заплатили 3500 грн за товар`
- `Боря Гуцул повернув 1000 грн у касу`
- `Орендар Петро заплатив 12000 грн оренди`
- `Склад сьогодні 30000 грн і 400 доларів, базар 4500 грн`
- `Переклали 10000 грн з каси на картку Миколи`

Команда `ші` показує, чи працює AI-режим.
