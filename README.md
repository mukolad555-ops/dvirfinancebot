# DvirFinance Bot v7.0 — Structured AI Accountant

## Головна зміна

ШІ більше не передає фразу назад у загальний список правил. Він спочатку визначає **один точний тип операції**, після чого програма запускає тільки один відповідний обробник.

Це прибирає помилку, коли повернення боргу могло бути записане як звичайна виручка, а борг залишався відкритим.

## Типи операцій

- виручка Склад / Базар;
- надходження на касу або картку;
- витрата з каси або картки;
- переказ між власними рахунками;
- обмін валют;
- новий борг;
- повернення боргу;
- платіж орендаря;
- ревізія.

## Приклади

```text
Болена повернула борг 3000 грн на картку Андрія
```

Результат: борг Болени зменшується на 3000 грн, картка Андрія збільшується на 3000 грн. Друга виручка не створюється.

```text
Болена перекинула 3000 грн на картку Андрія
```

Результат: звичайне надходження на картку Андрія; борг не змінюється.

```text
склад 5000 грн, базар 3000 грн
```

Результат: окремо фіксуються Склад і Базар, загалом 8000 грн додається до Каси.
